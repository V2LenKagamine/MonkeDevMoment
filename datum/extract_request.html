extract_request
/datum/extract_request

One crewmember's order of slime extracts or crossbreeds from xenobiology.

Vars

idPosition in GLOB.extract_requests, which is also how the consoles and windows refer to it.
item_idWhat the windows call the item: a slime color id for an extract, "effect|color id" for a crossbreed.
item_nameLowercase item name for logs and announcements.
item_typeTypepath of a single ordered item.
loadedWhat xenobiology has loaded so far, sitting inside whichever order console took it.
offerCredits held out of the requester's account until pickup, cancellation or a decline.
seenWhether a xenobiologist has opened it yet.

Procs

add_loadedCounts an item toward the order, and tells the requester once it's complete.
announceTells science over the radio and has every order console say it out loud.
describeWho ordered what, for log lines.
is_openStill needs somebody to do something about it.
pay_claimerPays the held offer to whoever filled the order.
refund_offerGives the held offer back to the requester.
to_listThe request as the windows see it. The viewer's account decides what counts as theirs.
