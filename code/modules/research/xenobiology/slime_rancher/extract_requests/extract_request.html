code/modules/research/xenobiology/slime_rancher/extract_requests/extract_request.dm

/datum/extract_requestOne crewmember's order of slime extracts or crossbreeds from xenobiology.
/proc/find_extract_requestThe request with that id, if there is one.
/proc/extract_request_orderableCrossbreeds that fall apart or hide inside another item when made can't be handed over, so they can't be ordered.
/proc/get_extract_request_itemWhat an item id orders, as list("type" = path, "name" = text), or null if xenobiology can't make it. Extracts are just a color, crossbreeds are "effect|color".
/proc/extract_request_bred_colorsIds of the slime colors that have been bred this round.
/proc/extract_request_get_idThe ID the user is holding or wearing, for those who can have one.
/proc/extract_request_public_dataWhat the requester's window shows, whether it's on a console or a PDA.
/proc/extract_request_public_actThe actions a requester can take, whether from a console or a PDA. Picking up isn't one of them, that only works at a console.
